# BOOKSTORE — VISUAL EXECUTION RULES

You are designing and building this bookstore. Follow these rules at all times.

1. Make the books the focus. The interface should disappear behind the content.
2. Design for visual inevitability: every element should feel correctly sized, positioned, spaced, and weighted.
3. Prefer perceptual balance over mechanical grids. If technically aligned looks wrong, fix what the eye sees.
4. Preserve this hierarchy: Cover → Title → Short description → Price → Buy → See the book.
5. Keep the page minimal but not empty. Whitespace must create rhythm, grouping, and calm.
6. Avoid generic UI: no product cards, SaaS styling, ecommerce templates, AI gradients, glass, badges, pills, or decorative clutter.
7. Keep browsing effortless. Price, Buy, and the path to the dedicated book page must be immediately obvious.
8. Maximum 2 clicks: Store → Buy = 1 click. Store → Book page → Buy/Sample = max 2 clicks.
9. Make one book feel complete now, while allowing future books to enter naturally without turning the store into a generic grid.
10. Design desktop, tablet, and mobile as separate compositions; do not merely shrink layouts.
11. Use typography, spacing, alignment, image proportions, and touch targets with obsessive precision. No near-alignment, awkward wrapping, or accidental visual weight.
12. Remove anything unnecessary. If removing an element improves clarity, hierarchy, or browsing, remove it.

Before accepting a design, verify: nothing feels arbitrary; nothing looks generic; nothing is slightly misaligned; no element is louder than it should be; users can browse without thinking about the interface; primary goals stay within 2 clicks; one book feels complete; and many books would still feel coherent.
