## Public / private repository boundary

This repository contains public website code, public discovery metadata and public-facing assets only.

The following remain outside the public web tree:

- paid full-content book packages and customer ZIPs;
- private production notes and unpublished working material;
- credentials, secrets and environment values;
- customer or payment data;
- private fulfilment and operational records.

This boundary is intentional: discoverability and provenance belong in the public site, while paid/private material stays outside the deployable public repository.

## Method and provenance
